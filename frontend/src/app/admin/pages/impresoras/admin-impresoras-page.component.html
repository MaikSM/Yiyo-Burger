Información sobre la conexión de impresoras

• Impresoras de Red (Ethernet/Wi-Fi): Ingresa la dirección IP estática asignada por tu router (ej: 192.168.1.100). El sistema utiliza el puerto 9100 estándar ESC/POS.

• Impresoras USB directas: Si la impresora está conectada por cable USB a la computadora servidor donde corre el backend, coloca la IP local 127.0.0.1 y asegúrate de tener un puente de impresión RAW/Spooler (como RawPrint o compartir en Windows mediante bucle de puerto 9100).
